# Original research notebooks

The full phase-by-phase history is indexed in [docs/PHASE_INDEX.md](../../docs/PHASE_INDEX.md).

1. `01_legacy_dnabert_experiments`: four original DNABERT experiment notebooks.
2. `02_legacy_longformer_experiments`: three original Longformer experiment notebooks.
3. `03_phases01_11c3_audit_and_models`: 17 benchmark audit, classification, MPRA and seed-shard notebooks (Phases 1–11C3).
4. `04_phases12_49_validation_and_reporting`: 38 validation, verification, statistics and manuscript-reporting notebooks (Phases 12–49).
5. `05_saved_versions`: five additional checkpoint/recovery versions, including failed attempts.

These are byte-identical source copies, including saved outputs. They have not been rerun for this archive. Historical status messages and reported values describe that version; current evidence and corrected interpretation are identified in the phase index. All original notebook paths, including identical backups, are mapped in `docs/ORIGINAL_SOURCE_INVENTORY.json`.

Use the six notebooks in the parent directory for the current saved-result reproduction workflow.
