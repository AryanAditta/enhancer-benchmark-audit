# Main figure files

The manuscript contains eight figure groups as 14 image objects. Figures 4a-c,6a-b and7a-d are separate graphs, each inserted separately in the Word manuscript. Figure 1 is the approved drawing. Figures 2-3 show the actual implemented methods. Figures 5 and 8 retain their multi-panel organization with consistent typography.

For every figure or separate graph: PDF and SVG are editable vector masters; PNG and TIFF are RGB 600-dpi exports. Files ending `_preview.png` are screen previews only and are not publication masters. The Word file embeds the full-resolution PNGs. All masters are 180mm wide, with Arial 5-7pt labels and 8pt bold lowercase panel letters. Model colors are DNABERT-2 blue, LegNet orange and MPRAnn teal. Published-paper visual inspiration was redrawn to reflect our actual methods; no published artwork was copied.

FIGURE_MANIFEST.json records source files and export hashes. Figure source data and frozen training are unchanged. Each component of Figures 4,6,7 is a distinct image file; no replacement collages for these groups are included.
